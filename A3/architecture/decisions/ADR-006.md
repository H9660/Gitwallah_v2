# ADR-006: A cheap fast model for builders, a different model family for the reviewer, chosen through one brain adapter

- **Date:** 2026-11-21
- **Status:** Superseded by [ADR-011](ADR-011.md) (provider and reviewer-model defaults). Kept for history.
- **Decision area:** D6 (models)

## Context
There are four builder agents per attempt, up to three attempts, and a two-round review loop. The repo is small (about 3k lines of backend JS), so builder tasks are local edits with clear tests. Cost must stay under a hard limit (assignment rule). A reviewer from the same model family as the implementer tends to share its blind spots. My notes: use an LLM for now, keep it switchable to SLMs with an `.env` change.

## Options considered
1. One strong model everywhere. Best quality, but the highest cost per run, and the reviewer shares the builders' biases.
2. A local SLM everywhere (Ollama). Free, but GitHub-hosted runners have no GPU, and small models are weak at multi-file edits.
3. **A brain adapter with per-role model names from repository variables. Default: `MODEL_BUILDER` = a cheap, fast, long-context model (Gemini Flash class via OpenRouter); `MODEL_REVIEWER` = a model from a different vendor (DeepSeek class via OpenRouter). `BRAIN=slm` switches to an OpenAI-compatible local endpoint.** ← chosen

## Decision
`brain.py` is the only code that talks to a model. It maps `role` → `MODEL_<ROLE>` (falling back to `MODEL_BUILDER`). It calls OpenRouter's OpenAI-compatible API with temperature 0.2 for builders and 0 for the reviewer, retries twice on errors with backoff, and records prompt/completion tokens and cost per call in the run record. A per-run token budget and USD budget stop the run with status `budget_hit`. Model slugs are repository **variables**, not code, so an experiment changes a variable, not the workflow. A hard credit limit is set on the OpenRouter key before the first run.

## Consequences
- + The reviewer uses a different family by default, a cheap structural defence against rubber-stamping (ADR-008).
- + Swapping models needs no code change, so experiments are cheap and repeatable.
- − Two vendors means two sets of JSON-output quirks. Mitigated by tolerant JSON extraction and one repair retry.
- − Model slugs on OpenRouter change over time. The README records the exact slugs used for the reported runs.
